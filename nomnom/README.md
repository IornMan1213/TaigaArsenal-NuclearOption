# NOMNOM

`TaigaArsenal.json` is a draft listing for [NOMNOM](https://github.com/KopterBuzz/NOMNOM), the mod registry used by NOMM. It has
not been submitted. Its `artifacts` list is empty until the first public release: add that release's zip
(`TaigaArsenal_<version>.zip`, its download URL and sha256) before submitting. NOMNOM takes the first asset of each GitHub release.
